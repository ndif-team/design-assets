## NNterp

The NNterp library is a unified interface for all transformer models that puts the best NNsight practices for LLMs in everyone's hands, providing a standardized interface for mechanistic interpretability research across all transformer architectures and providing efficient implementation of common methods for interpreatbility workflows. It acts as the backend for the Workbench.

## Logo Concept

Standardization drawn as signal convergence.

- From the left edge, **three slate-gray polylines enter, each with a visibly different rhythm** — one with tight jagged zigzags, one with wide shallow bends, one stepped like a square wave. These are the heterogeneous architectures: same data, incompatible shapes. Each starts from its own small gray node at the left edge, the three lines vertically distributed (top, middle, bottom).
- The three lines converge on a **single large junction node** at roughly the horizontal center of the canvas.
- From the junction node, **one clean gradient line-plot arrow exits to the right** — the NNsight arrowhead, the family stroke weight, sweeping periwinkle → azure (the fuchsia end of the gradient can begin at the junction node itself, so the node glows fuchsia and the output completes the sweep). One or two small nodes punctuate the output line, as on the Workbench "W."
- Family tie-in to Workbench (NNterp is its backend): the junction node sits on a **vertical light-gray rail**, styled exactly like one Workbench slider track, so the big node reads as a knob. One rail only — a subtle quotation, not a copy.

The mark reads left to right as the tool's promise: many messy interfaces in, one standard interface out. Composition-wise it forms a sideways "Y" / funnel with strong horizontal flow, consistent with every other mark in the family.

At favicon size: two input lines instead of three, junction node, short output arrow; drop the rail.
