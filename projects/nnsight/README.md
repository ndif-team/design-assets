# NNSight

The NNSight library is an open-source PyTorch library at the core of the ecosystem allowing researchers to write code to inspect, modify, and customize any model's internal computations and execute it locally or remotely on NDIF. The name is a wordplay on "Insight" and "NN" for "Neural Networks".

## Logo Concept

The NNSight logo is already available. The logo includes two N's for the "Neural Networks" aspect, shaped as arrows to represent the interventions that the library enables: users can read from one neuron of a model, and patch its activation to another one to change the model's behavior. The two N's are gradient-colored to represent the dynamic nature of the intervention, while the neuron lines are dark gray to represent fixed units within model's structure.
