The Workbench is a web interface for interactive interpretability, allowing users to explore model internals, run lenses, and steer behavior directly in the browser, backed by NDIF's remote execution. The tool is mostly intended for pedagogical purposes at the moment, but in the future could support more complex analyses. 

## Logo Concept

The Workbench logo is already available. The logo contains a gradient-colored line creating a "W" for Workbench, reflecting the graphical nature of the UI. The line is laid over a set of knobs to reflect user-interaction capabilities.
